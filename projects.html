AI & Machine Learning

Smart Spending with AI

An intelligent personal finance management platform designed to process raw transaction histories, extract financial indicators, and leverage Artificial Neural Networks (ANN) to predict overspending risks and provide dynamic, voice-enabled recommendations.

Source Code
Smart Spending with AI — Interactive Dashboard

The Problem

Traditional personal finance management relies heavily on manual bookkeeping and static spreadsheets. These passive tools only record historical data without offering dynamic foresight, leaving users blind to impending overspending risks and budget deficits until after they occur.

The Solution

Smart Spending with AI transforms passive tracking into proactive decision support. By executing automated data preprocessing and feature extraction, the integrated Artificial Neural Network evaluates real-time income-to-expense ratios, forecasts budget shortfalls, and delivers actionable savings advice.

System Architecture & Data Flow

The application follows a multi-layered ASP.NET architecture where user entries flow seamlessly through feature extraction and model prediction down to interactive visual reports:

1. Data Ingestion

User logs income, daily expenses, and category budgets into SQL Server.

2. Preprocessing & Feature Extraction

Normalizes data and extracts features (savings ratio, budget utilization, expense trends).

3. ANN Model Inference

Backpropagation neural network predicts overspending risk and evaluates savings potential.

4. Dynamic Insights & Alerts

Triggers visual dashboards, automated notifications, and voice-assisted recommendations.

Core Highlights & Technical Metrics

Developed using an enterprise-grade ASP.NET web framework paired with C#.NET backend services, the system offers superior prediction performance compared to conventional machine learning models.

  • 98.98% Model Accuracy: Outperforms SVM (94.8%), KNN (92.4%), and Decision Trees (90.6%) in classifying financial risk behavior.
  • Automated Feature Engineering: Converts raw transaction logs into structural indicators such as monthly expense variance and category utilization ratios.
  • Proactive Warning Engine: Automatically detects high-risk categories and alerts users prior to budget limit breaches.
  • Multimodal Accessibility: Integrates dynamic visual charts along with speech synthesis (Text-to-Speech) for spoken AI financial advice.
Key Technologies:
ASP.NET C# Artificial Neural Networks (ANN) SQL Server JavaScript (ES6+) HTML5 / CSS3 Chart.js
Computer Vision & AI

Automated Attendance Manager

A contactless, real-time facial recognition system designed to eliminate proxy marking and streamline attendance logs using computer vision algorithms and a lightweight web framework.

Source Code More Details Hide Details
Automated Attendance Manager — Web Control Panel

The Problem

Conventional attendance tracking—such as manual name call-outs, paper sign-in sheets, or RFID physical cards—is time-consuming, highly susceptible to proxy marking, and prone to administrative recording errors.

The Solution

The Automated Attendance Manager implements real-time facial recognition to verify individual identities touchlessly. By capturing live video feeds via OpenCV and processing frames against verified image databases, attendance is logged instantly with precise timestamps.

System Processing Architecture

The computer vision pipeline processes live camera frames through standard image processing stages down to real-time database logging:

1. Video Stream Capture

Captures real-time camera frames through OpenCV image input feeds.

2. Face Detection & Preprocessing

Applies Viola-Jones Haar Cascade classifiers to identify facial regions and normalizes image frames to grayscale.

3. Feature Encoding & Face Recognition

Extracts facial embeddings and compares features against stored database templates using face matching algorithms.

4. Timestamped Logging & UI Update

Logs attendance automatically into spreadsheet databases and displays confirmation statuses on the Flask web interface.

Project Metrics & Core Features

Built using Python, OpenCV, and Flask, the platform delivers an accessible, high-performance administrative management system for educational and workplace environments.

  • High Recognition Accuracy: Achieved 85%–95% accuracy under varying lighting conditions and facial angles during real-time evaluations.
  • Automated Timestamps: Instantly updates attendance records without manual administrative intervention.
  • Web Management Dashboard: Features administrative controls for adding, updating, and monitoring student lists and logs.
  • Proxy Prevention: Secure biometric authentication prevents buddy-punching and fraudulent entries.
Key Technologies:
Python OpenCV Viola-Jones Algorithm Flask Framework Haar Cascades HTML5 / CSS3
